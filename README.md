# Tjørring Entreprenør – Meme Edition

En useriøs demo-hjemmeside til Tjørring Entreprenør.

Slogan:

> Åh Nej Tjørring Entreprenør Er På Vej

## Filer

- `index.html` – selve hjemmesiden
- `styles.css` – design og responsivt layout
- `script.js` – PANIK-popup, fake live tracking og easter egg
- `assets/logo.png` – logo

## GitHub Pages

1. Opret et nyt repository på GitHub.
2. Upload alle filer og mapper fra dette projekt.
3. Gå til **Settings → Pages**.
4. Under **Build and deployment**, vælg **Deploy from a branch**.
5. Vælg `main` og mappen `/ (root)`.
6. Gem.

Efter kort tid får repository'et en offentlig GitHub Pages-adresse.

## Cloudflare Pages

Projektet er også klar til Cloudflare Pages.

- Framework preset: `None`
- Build command: lad feltet være tomt
- Build output directory: `/`

Der er ingen database eller backend i denne version.
